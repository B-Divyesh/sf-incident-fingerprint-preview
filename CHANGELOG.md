# Changelog

All notable changes follow Keep a Changelog. This project uses semantic
versioning from `0.1.0`.

## [Unreleased]

### Added

- One-click browser demo with a persistent sample label, reset, and clean exit.
- Bundled CLI `demo` command with isolated temporary output.
- Claim registry and outcome-based browser, privacy, consumer, and CLI checks.
- Product-styled 404 page and complete social, canonical, and touch metadata.

### Changed

- Replaced metaphorical landing copy with the concrete job, audience, and
  first action.
- Raised core editor and help text to 16px and expanded desktop navigation
  targets to at least 44px.

## [0.1.0] - 2026-08-28

### Added

- Offline Rust CLI/library with generic, Sentry, Bugsnag, and Rollbar adapters.
- Fingerprint rule parser with fallback expressions.
- Human and JSON split/merge reports with privacy-preserving frame summaries.
- Static live preview, documentation, privacy, terms, and offline shell.
