Privacy

Privacy for the browser evaluator

Effective 5 September 2026

Fingerprint Preview has no accounts, analytics, advertising, tracking pixels, cookies, or server-side event ingestion.

The evaluator processes pasted and selected files in browser memory. It does not transmit or save them.

What the site receives

The host may receive your IP address, browser name, requested path, and request time.

These details support security and file delivery. The product does not connect them to evaluator content.

Local processing

Event JSON, rules, and reports stay in the current browser tab.

A service worker caches public application files for offline use. It does not cache pasted content.

Closing or reloading the tab discards your evaluator input.

Your responsibility

Scrub event samples before importing them.

Reports omit source context, arguments, request data, and frame line numbers. Messages and filenames can still contain sensitive data.

Questions

Open a privacy issue in the public repository. Do not attach sensitive event fixtures.
