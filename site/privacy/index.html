Privacy / plain language

Event data stays in your tab.

Effective 28 August 2026

Fingerprint Preview has no account system, analytics, advertising, tracking pixels, cookies, or server-side event ingestion. The live evaluator processes pasted and selected files in your browser memory. It does not transmit or persist them.

What the site receives

Normal hosting infrastructure may temporarily receive standard request metadata such as IP address, browser user agent, requested path, and time for security and delivery logs. The product does not add identifying telemetry or correlate those requests with evaluator content.

Local processing

Event JSON, rules, and generated reports stay in the current browser tab. A service worker caches public application files for offline use; it does not cache your pasted content. Closing or reloading the tab discards the evaluator input.

Your responsibility

Scrub event samples before importing them. The report intentionally omits source context, arguments, request data, and frame line numbers, but messages and filenames can still contain personal or secret data.

Questions

Open a privacy issue in the public repository. Do not attach sensitive event fixtures.
