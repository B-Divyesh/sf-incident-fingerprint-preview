Three steps

How it works

  1. 1

    Scrub a fixture

    Export a representative event set, remove customer data, and retain existing group IDs.

  2. 2

    Write the fingerprint

    Combine stable exception and frame fields with an explicit fallback.

  3. 3

    Review the changes

    Check each baseline split and cross-group merge before rollout.

What it does not do

It reads common Sentry, Bugsnag, and Rollbar JSON shapes. It does not copy any vendor’s private grouping logic.
